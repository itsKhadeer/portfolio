# **App Name**: Khadeer Ahmed Portfolio

## Core Features:

- Hero Animation: Interactive Hero Section: An animated full-width hero section to introduce Khadeer with a dynamically revealed tagline.
- Animated Skills: Skill Showcase: Display technical skills with animated tooltips and categorized grid or scrollable layout.
- Dynamic Project Filter: Project Filtering: Enable users to filter projects by tech stack with animated card transitions and modal pop-ups for detailed views.
- Animated Timeline: Timeline Experience: Present professional experience through an animated timeline, highlighting company logos and role descriptions.
- Scroll Animations: GSAP Scroll Trigger Animations: Implement various scroll-triggered animations to reveal sections, creating a dynamic scrolling experience.
- Animated Contact Form: Contact Form: Provide an animated contact form with input validation and a Firebase Function to handle email submissions.
- Dynamic Resume: Dynamic content updating: The resume button downloads the latest version from Firestore

## Style Guidelines:

- Primary color: Deep blue (#1A237E) to convey professionalism and technical expertise. The choice reflects reliability, stability, and confidence.
- Background color: Very light gray (#F5F5F5) to create a clean and modern look.
- Accent color: Bright yellow (#FFEB3B) to draw attention to CTAs and interactive elements, promoting engagement.
- Headline font: 'Space Grotesk' (sans-serif) for a techy, modern headline style.
- Body font: 'Inter' (sans-serif) for a clean and readable body text.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use Material Design icons to match Material 3 / Material Components.
- One-page scroll layout with a sticky navbar to provide easy navigation.
- Responsive design adapting from mobile to 4K screens ensuring optimal viewing experience.
- Use GSAP with scroll triggers for animated section reveals.
- Use microinteractions on interactive elements to provide feedback and enhance user experience.
- Incorporate page transitions to maintain user context while browsing.
